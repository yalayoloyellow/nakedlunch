# nakedlunch

**Офлайн-генератор песенных строк-заготовок.** Русский язык, macOS, ноль сети.

Генератор тупой: грамматика, морфология, разметка ударений. Фильтр умный:
каскад отсева по рифме, слогам, клаузуле, банальности, сцепке слов, тавтологии,
мату, чёрному списку и истории показов. Никакой нейросети-автора, ни одного
внешнего вызова — всё считается на процессоре из локальных таблиц.

Второй источник строк — **корпус**: настоящие тексты, нарезанные на фрагменты,
из которых отбор достаёт готовые куски. Пропорцию с генератором задаёт одна
крутилка.

---

## Установка

```sh
python3.12 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python launch.py
```

`launch.py` соберёт интерфейс, поднимет сервер на свободном порту и откроет
окно. Двойной клик по `run.command` делает то же самое.

Нужны Python 3.12 и Node 20+. Программа стартует сразу: генератор работает на
таблицах, которые лежат в репозитории.

## Первый корпус

Книга заливается через интерфейс, без терминала. Дальше всё происходит само:

```
файл → нарезка на фрагменты → ударения → индекс → генерация
```

Прогресс каждой ступени виден в шапке. На книге в девять килобайт вся цепочка
занимает секунды; на сорока книгах — часы, и это разовая работа.

## Где живут данные

В репозитории их нет и не будет.

| где | что |
|---|---|
| `data/` | принятые строки, история показов, избранное, положения крутилок, журнал |
| `~/Documents/nakedlunch/data` | нарезанные фрагменты источников |
| `~/Documents/nakedlunch/тексты` | листы редактора |
| `~/Documents/nakedlunch/записи` | записи голоса |

Пути переопределяются переменными среды `NAKEDLUNCH_DATA`, `NAKEDLUNCH_VAULT`,
`NAKEDLUNCH_RECORDINGS`.

## Что внутри

**Четыре режима.** Строфа по команде · редактор листов с папками и
автосохранением · фристайл, где текст живёт на сцене поверх звуковой
визуализации · пайплайн, собирающий из звеньев целую вещь.

**Двусторонняя ручка «Банальность».** Слева язык максимально затёртый, справа
нетронутый, посередине она не влияет. Вторая её ось — сцепка соседних слов,
выученная из самого корпуса: затасканное у одного автора не будет затасканным
у другого.

**История как инвариант.** Показанное не возвращается, пока история не очищена.
Нет материала на тему — программа отказывает честно.

**Карта воронки.** Сколько строк и книг доживает до каждой ступени отбора —
числом, а не на словах.

**Чёрный список** слов и словосочетаний со счётчиком «сколько строк убирает»,
по начальным формам и целыми словами.

Подробности устройства и все замеры — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Если что-то сломалось

Причина показывается на экране, а не прячется в файл. Настройки → **Лог** →
«сохранить отчёт на рабочий стол»: файл ложится на стол и открывается в
проводнике, внутри — среда, состояние данных и журнал всех запусков.

Ошибка отмечается счётчиком на шестерёнке. При нуле ошибок его не существует.

## Сборка артефактов

Тяжёлые таблицы в git не едут — около 1.6 ГБ, пересобираются локально.

Сборка ударений требует зависимостей, не нужных самому приложению:

```sh
pip install ruaccent "transformers<5"
```

Пятёрка обязательна: вызов ruaccent ломается на transformers 5.x.

```sh
python tools/build_rhyme_index.py   # словарь рифм для попапа, ≈4 мин
python tools/build_nl_rhyme.py      # кэш ударений корпуса
python tools/build_nl_index.py      # колоночный индекс, ≈160 с
```

Порядок важен: индекс печётся из кэша ударений.

**Модель векторов** `core/data/navec.tar` (51 МБ, MIT) в репозиторий не положена:
это чужая работа со стабильной ссылкой. Без неё работает всё, кроме семантики
темы. Взять [navec_hudlit_v1_12B_500K_300d_100q.tar](https://github.com/natasha/navec).

## Тесты

```sh
.venv/bin/python -m pytest tests/ -q
```

555 тестов. Часть проверяет конкретную выдачу, часть — свойства распределений:
ни одна книга не берёт больше удвоенной своей доли в пуле, показанное не
возвращается, ручка смещает выбор в обе стороны.

Тесты, которым нужен собранный артефакт, честно пропускаются с указанием, чего
не хватает. На чистом клоне: `494 passed, 58 skipped`.

## Устройство каталогов

```
core/       домен: генерация, разбор, отбор, корпус, индекс. О фронтенде не знает.
api/        тонкий Flask-адаптер над core. Логики в нём нет.
interface/  React-клиент.
tools/      сборщики таблиц и индексов, офлайн и разово.
tests/      555 тестов.
```

## Чего здесь нет

- **Windows и Linux.** Программа писалась и проверялась под macOS.
- **Английского.** Морфология, ударения, рифма — только русский.
- **Сети.** Инструмент работает в самолёте.
- **Автора-нейросети.** Строки собирает грамматика, решает отбор и человек.
