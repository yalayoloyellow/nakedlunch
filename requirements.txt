#   pip install ruaccent "transformers<5"
# ONNX-вызов ruaccent ломается на transformers 5.x (в подаче нет 'token_type_ids' —
# токенизатор сменил форму вывода между мажорными версиями). Поймано 2026-07-13,
# когда голый `pip install ruaccent` притянул transformers 5.13.1. Сам ruaccent
# работает на onnxruntime (процессор, ~10 мс на фрагмент), а transformers нужен
# только ради токенизатора — то есть этот пин не возвращает torch.
#
#   tools/build_nl_rhyme.py   -> core/data/nl_rhyme.jsonl  (+ ruaccent: ключи рифм корпуса)
#   tools/build_rhyme_index.py-> core/data/rhyme_index.json (+ ruaccent: словарь ударений)
#   tools/build_nl_index.py   -> core/data/nl_index/        (колонки отбора)
#   tools/build_nl_addr.py    -> core/data/nl_addr/         (адреса строк; нужны
